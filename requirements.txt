# Optional but recommended on Kaggle:
#   flash-linear-attention -- Qwen3.5's gated-delta-rule layers fall back to a
#   reference implementation without it. Linux wheels are more reliable than
#   Windows. The only one of these two kernels with a measurement behind it: a
#   555-step T4 run went 4305s -> 3960s, so 1.09x. Worth having, but nowhere
#   near the order of magnitude the fallback path implies.
#
#   causal-conv1d -- this note used to claim it was "the one that actually
#   matters" and that the run stays launch-bound at ~7 s/step without it. Both
#   claims were tested and are wrong. A run with fla and WITHOUT causal-conv1d
#   finished in 3977s (7.17 s/step) against 3960s (7.14 s/step) with it: 0.4%.
#   It is also the one that cannot be installed on Kaggle -- it builds against
#   nvcc and the wheel build fails outright on the current image, which is the
#   normal state of a Cell 1 run, not a broken session. transformers prints a
#   "falling back to its reference PyTorch implementation" note; that note is
#   noise. ~7 s/step is what this model costs on a T4. Install it only if you
#   want to see the warning go away.
